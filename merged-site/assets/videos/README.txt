Game preview clips
==================

Each game in the drawer has a short branded preview clip:

  assets/videos/<gameKey>.mp4   1280x800 (16:10), H.264, 30fps, 5.5s, muted
  assets/videos/<gameKey>.jpg   poster frame used before the video starts

The drawer swaps <gameKey>.mp4 when a game tab is selected. If a clip is
missing or fails to decode, the panel falls back to the placeholder box
"ویدیو به‌زودی" (the onerror handler removes the has-video class).

Game keys in use:
premium, codm, freefire, pubg, football, plato, soccerstars, eightball,
gift-adidas, gift-amazon, gift-steam, gift-skype, gift-xbox, gift-psn,
gift-roblox, gift-razer, gift-freefire, gift-nike, gift-netflix,
gift-nintendo, clashmini, brawlstars, clash, clashroyale

Regenerating
------------
The clips are generated from the same data as the page, so titles, product
counts and starting prices stay in sync with index.html:

  cd ../../tools/preview-videos
  npm install
  node make-videos.js              # all games (~3 minutes)
  node make-videos.js codm clash   # just these keys
  node verify.js                   # confirm every key has an mp4 + jpg

Design notes: each clip uses the storefront palette, the game's accent colour
sampled from its product artwork, and Persian type rendered with Vazirmatn.
No third-party game footage or logos are used.

Portrait posters for the same games live in assets/posters/<gameKey>.jpg
(1080x1350) and are generated by the same tool: node make-posters.js
